# Каталог дверей DK

PWA без библиотек и сборщика. Данные хранятся в `localStorage` как JSON.

## Запуск

Service worker работает только через HTTP(S), поэтому откройте папку локальным сервером:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/doors-pwa/`, если сервер запущен из `/mnt/data`, либо `http://localhost:8080/`, если сервер запущен внутри папки приложения.

## Файлы

- `dom.js` — создание и обновление интерфейса.
- `storage.js` — чтение, сохранение и сброс локального JSON.
- `csv.js` — импорт, разбор и экспорт CSV.
- `app.js` — состояние приложения и обработчики действий.
- `seed-data.js` — исходный список дверей из предоставленного CSV.
- `sw.js` и `manifest.webmanifest` — установка и офлайн-работа PWA.
